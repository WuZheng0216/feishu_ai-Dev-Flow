# 演示脚本

## 环节一：平台能力展示

1. 打开 Web 控制台。
2. 输入一个准备好的产品需求。
3. 点击创建并启动 Pipeline。
4. 展示需求分析和方案设计阶段自动完成。
5. 在方案审批检查点点击 Reject，输入驳回理由，展示 Pipeline 回退重做。
6. 再次进入方案审批后点击 Approve。
7. 展示代码生成阶段写入 `workspace/demo` 的真实文件变更，并在阶段产物中查看 diff。
8. 展示测试生成、代码评审自动流转。
9. 在最终评审检查点点击 Approve。
10. 展示交付摘要、阶段产物、最终状态。

## 环节二：现场命题挑战

评委给出需求后，将目标代码库设置为平台自身或 `workspace/demo`，用同一条 Pipeline 现场跑通。

## 环节三：技术答辩

重点解释：

- 为什么 Pipeline 和 Agent 解耦。
- 为什么保留 Human-in-the-Loop。
- Agent 输入输出契约如何保证可控。
- Reject 如何携带理由回退重做。
- 后续如何把当前受控 workspace diff 升级为真实 Git 分支、MR、代码索引和飞书审批。
